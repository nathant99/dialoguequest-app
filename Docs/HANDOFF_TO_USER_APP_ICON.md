# Handoff to User — App Icon (6-variant Liquid Glass set)

The agent cannot author or edit `Apps/DialogueQuest/DialogueQuest/Assets.xcassets/AppIcon.appiconset/Contents.json` (forbidden glob per `@.claude/rules/xcode-agent-safety.md`). The 6-variant Liquid Glass icon set is generated by Apple's **Icon Composer** GUI app and dropped into the asset catalog as a single `.icon` bundle — both steps GUI-only.

## What the 6 variants are

Per `@.claude/rules/liquid-glass.md` § "Icon Composer (standalone app)" the iOS 26 icon system ships **6 rendered variants** for every app:

| Variant | When iOS uses it |
|---|---|
| Default (color) | Light mode, default tinting |
| Dark | Dark mode |
| Tinted (mono) | User-chosen color tint mode |
| Clear (light) | iOS 26.1+ glass-clear treatment, light mode |
| Clear (dark) | iOS 26.1+ glass-clear treatment, dark mode |
| Tinted-on-clear | iOS 26.1+ tinted-on-glass treatment |

Icon Composer renders all six from a single source design.

## DialogueQuest icon design brief

Per `@Docs/IMPLEMENTATION_HANDOFF.md` § 1 and `@Docs/TECHNICAL_DESIGN.md` § "Delight & Emotional Design":

- **Hero mascot**: **Patter** — a two-toned speech bubble with a wobbly tail. Two tones: rust (`#A05A4B`) + cream (`#F1E7D8`).
- **Aesthetic register**: chunky-cartoon (Toca-Boca / Animal-Crossing register per the writing-craft cluster style); thick `#2A1F1A` outline; soft solid fills.
- **Background**: cream wash with a subtle two-character speech-bubble silhouette echoing the writing-craft register.
- **Hero color**: `#A05A4B` (Conversation rust) — also primary CTA / mascot background tint / ForgeAdventure zone tag.
- **No text in the icon** — Apple HIG; the wordmark lives outside the glyph.

A single 1024×1024 source PNG of Patter (chunky outlined; centered; cream background) is sufficient — Icon Composer derives the 6 variants automatically. If you'd like the agent to file a generation handoff for the source PNG, file `Docs/HANDOFF_TO_HUB_PATTER_APP_ICON_PNG.md` to hub (asset-generation ownership per `@.claude/rules/portfolio.md`).

## What you need to do in Xcode (~15 min, AFTER the source PNG lands)

### Step 1 — Open Icon Composer

1. Launch **Icon Composer** from Applications (ships with Xcode 26+) or via Spotlight
2. **File → New** → drop the Patter 1024×1024 source PNG into the canvas
3. Adjust offset / scale so the speech-bubble glyph fills ~80% of the safe area (Icon Composer shows the rounded-square mask + safe-area guides)
4. Preview the 6 variants in the right-hand panel; tweak source if Tinted or Clear-dark variants look off (typically you may need to bump foreground contrast for the Tinted variant)
5. **File → Export** as `DialogueQuest.icon` — Icon Composer emits a single `.icon` bundle

### Step 2 — Add to Asset Catalog

1. Open `DialogueQuest.xcworkspace` in Xcode
2. In the Project Navigator, find `Apps/DialogueQuest/DialogueQuest/Assets.xcassets`
3. Right-click `Assets.xcassets` → **New App Icon** (Xcode 26+ adds the new icon-bundle-style entry)
4. Drag the `DialogueQuest.icon` bundle into the new entry
5. Verify the 6 variants populate
6. `git status` should show changes to `Apps/DialogueQuest/DialogueQuest/Assets.xcassets/` — the agent will stage + commit per the carve-out

### Step 3 — Build verify

1. Cmd+B (Build)
2. Launch on iPhone 17 simulator → confirm the icon appears on Springboard
3. Toggle Settings → Display → Appearance → Dark — confirm the Dark variant renders
4. Settings → Wallpaper → tint → confirm the Tinted variant renders

## What this handoff does NOT cover

- **Source PNG generation** — separate handoff; can be filed to hub via `Docs/HANDOFF_TO_HUB_PATTER_APP_ICON_PNG.md` per portfolio asset-generation ownership rule
- **App Store icon (1024×1024)** — handled by the same `.icon` bundle; App Store Connect picks up the default variant automatically
- **iOS 26.0-only fallback** — the 6-variant `.icon` bundle is iOS 26.1+; pre-26.1 devices fall back to the default variant (Xcode handles this automatically; no agent action needed)

## When you've completed Steps 1–3

`git status` will show the modified asset catalog. Commit per the standard Xcode-managed-files carve-out, or leave staged for the next agent session to pick up.

If Icon Composer surfaces a variant that looks visibly off (most common: Tinted mode losing contrast on the speech-bubble outline), iterate on the source PNG and re-export. The .icon bundle replacement is a clean overwrite.
