# Handoff to Hub — Curating Together parent guide PDF

Direction: **app → hub**. DialogueQuest's Companion Pack currently ships 3 PDFs (cast poster / coloring / parent letter). Phase 4 row 158 anthology curation shipped 2026-06-23 (PR #103) — kids can now curate themed collections of their best dialogue trees. The Companion Pack needs a 4th PDF for parents + educators introducing this new surface.

## The ask

Generate `curating_together.pdf` and distribute it to `dialoguequest-app/Libraries/Sources/AppFeature/Resources/CompanionPack/` alongside the existing 3 PDFs. Update `companion_pack.json` to include the new entry. The app session will then add a one-line entry to `CompanionPackEntry.bundled` (already reserved in source comments) to surface the PDF in the in-app Companion Pack list.

## Spec

- **Format**: PDF, US Letter portrait, ~1-2 pages
- **Audience**: Parents + educators of kids 9-14
- **Tone**: Warm, plain-language, register-clean (per `.claude/rules/distributed-narrative.md` § R-CHAPTER-REGISTER stoplist — no engineering jargon)
- **Content outline** (suggested):
  1. **What's new**: "Anthology curation — your kid can now organize their favorite dialogue trees into themed collections."
  2. **The five themes**: First Conversations / Quiet Conflicts / What They Didn't Say / Branching Moments / Three-Voice Scenes — one sentence per theme explaining what writing-craft surface it spotlights
  3. **Why it matters for the writer**: Curating IS writing-craft — picking which trees belong together teaches noticing patterns, voice consistency, branch-meaningfulness
  4. **Conversation prompts** (3-5 questions a parent or educator can ask while their kid curates):
     - "Which scene felt the hardest to write? Did it make the collection?"
     - "What do these three scenes have in common — and what's missing?"
     - "If you read this collection out loud, what does each character's voice sound like?"
     - "What's a theme you'd want to write more of?"
  5. **No screens needed**: framing that the conversation works while folding laundry / driving / waiting in line. (Aligns with the existing Companion Pack philosophy.)
- **Brand register**: matches existing 3 PDFs — Spark & Anvil warm palette (forge orange + spark gold + anvil charcoal); chunky-cartoon mascot illustrations of Patter + 1-2 cast members appropriate to the curation theme

## Why hub owns this

Per `.claude/rules/portfolio.md` § "Asset generation ownership": hub owns ALL portfolio-wide asset generation. The Companion Pack PDFs were generated by `labsmith scripts/build_companion_pack.py` (queue #332) per the existing `companion_pack.json` provenance line. The new PDF should ship through the same pipeline.

## What's already in place app-side

- The existing `CompanionPackView.swift` renders entries from `CompanionPackEntry.bundled` dynamically — adding a 4th entry is a one-line edit when the PDF lands
- `Bundle.module.url(forResource:withExtension:)` lookup is wired (the entry returns nil URL gracefully if the file is missing — no crash)
- `Resources/CompanionPack/` is already processed by `Package.swift` `.process("Resources/CompanionPack")` rule
